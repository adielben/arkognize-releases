# Arkognize for Revit

Model verification add-in for Autodesk Revit 2025 and 2026.

## Download

Get the latest installer from the **[Releases page](https://github.com/adielben/arkognize-releases/releases/latest)**.
Download `Arkognize-Setup-<version>.exe`.

## Install

1. Run `Arkognize-Setup-<version>.exe`.
2. Windows may show a SmartScreen warning, because the installer is not signed yet.
   Click **More info**, then **Run anyway**.
3. Follow the steps. No administrator rights are needed.
4. If Revit is open, restart it.

The add-in is installed for every supported Revit version found on your computer.

## Updates

Arkognize updates itself. When Revit starts, it checks for a new version and installs it
in the background. You can keep working; the new version starts the next time you open Revit.

## Requirements

- Windows 10 or 11, 64-bit
- Revit 2025 or Revit 2026
- Network access to `github.com`, `bimiq.ciamlogin.com` and the Arkognize service
